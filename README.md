# C++ Modules for 42 Network

This repository contains my solutions for the C++ modules of the 42 network curriculum. Each module is designed to teach a specific set of concepts in C++, from the basics to more advanced topics.

## Summary of Modules

### [CPP Module 00: Introduction to C++](CPP_00/README.md)

A gentle introduction to C++, covering the basic syntax, classes, and I/O.

- **Concepts:** Namespaces, Classes, Encapsulation, `this` pointer, I/O streams.
- **Projects:** `megaphone`, `PhoneBook`, `Account`.

### [CPP Module 01: Memory, Pointers, and References](CPP_01/README.md)

Dives into memory management, pointers, and references.

- **Concepts:** `new` and `delete`, pointers vs. references, file I/O.
- **Projects:** `Zombie`, `ZombieHorde`, `Weapon`, `Harl`.

### [CPP Module 02: Ad-hoc Polymorphism and Operator Overloading](CPP_02/README.md)

Introduces operator overloading and the Orthodox Canonical Form.

- **Concepts:** Operator Overloading, Orthodox Canonical Form, Fixed-Point Numbers.
- **Projects:** `Fixed` number class.

### [CPP Module 03: Inheritance](CPP_03/README.md)

Explores inheritance, a core concept of OOP.

- **Concepts:** Inheritance, Function Overriding, The Diamond Problem.
- **Projects:** `ClapTrap`, `ScavTrap`, `FragTrap`, `DiamondTrap`.

### [CPP Module 04: Subtype Polymorphism, Abstract Classes, and Interfaces](CPP_04/README.md)

Covers polymorphism, abstract classes, and interfaces.

- **Concepts:** Polymorphism, Virtual Functions, Abstract Classes, Deep vs. Shallow Copy.
- **Projects:** `Animal`, `Cat`, `Dog`, `Brain`.

### [CPP Module 05: Exceptions](CPP_05/README.md)

Focuses on handling errors using exceptions.

- **Concepts:** `try`, `throw`, `catch`, Exception Safety.
- **Projects:** `Bureaucrat`, `Form`, `Intern`.

### [CPP Module 06: C++ Casts](CPP_06/README.md)

Explains the different types of casts in C++.

- **Concepts:** `static_cast`, `dynamic_cast`, `const_cast`, `reinterpret_cast`.
- **Projects:** Scalar conversion, Serialization, Type identification.

### [CPP Module 07: C++ Templates](CPP_07/README.md)

Introduces templates for writing generic code.

- **Concepts:** Function Templates, Class Templates.
- **Projects:** `swap`, `min`, `max`, `iter`, `Array`.

### [CPP Module 08: Standard Template Library (STL)](CPP_08/README.md)

An introduction to the STL.

- **Concepts:** STL Containers, Algorithms, Iterators.
- **Projects:** `easyfind`, `Span`, `MutantStack`.

### [CPP Module 09: Advanced C++ Topics](CPP_09/README.md)

Covers advanced topics and practical problem-solving.

- **Concepts:** Parsing, Advanced STL, Algorithm Design.
- **Projects:** `BitcoinExchange`, `RPN`, `PmergeMe`.

## How to Use

Each module is in its own directory. Inside each module's directory, there are subdirectories for each exercise. Each exercise has its own `Makefile`. To compile an exercise, `cd` into its directory and run `make`.
