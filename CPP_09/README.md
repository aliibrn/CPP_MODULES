# C++ Module 09: Advanced C++ Topics

This final module covers a few advanced topics and brings together many of the concepts learned in the previous modules. It focuses on practical problem-solving using C++ and the STL.

## Concepts Covered

- **Parsing:** Reading and interpreting data from files and strings.
- **Advanced STL Usage:** Combining different STL containers and algorithms to solve complex problems.
- **Algorithm Design:** Implementing more complex algorithms and considering their efficiency.
- **C++11 Features:** (Implicitly) Using modern C++ features for cleaner and more efficient code.

## Exercises

### Exercise 00: Bitcoin Exchange

- **Files:** `ex00/BitcoinExchange.cpp`, `ex00/main.cpp`
- **Purpose:** To practice file parsing and data management. You will write a program that takes a file of bitcoin prices and a file of your own bitcoin holdings, and calculates the value of your holdings on different dates.

### Exercise 01: RPN

- **Files:** `ex01/RPN.cpp`, `ex01/main.cpp`
- **Purpose:** To implement a Reverse Polish Notation (RPN) calculator. This exercise requires you to parse a string of numbers and operators, and use a stack to perform the calculations.

### Exercise 02: PmergeMe

- **Files:** `ex02/PmergeMe.cpp`, `ex02/main.cpp`
- **Purpose:** To implement the merge-insert sort algorithm (also known as the Ford-Johnson algorithm) for sorting a sequence of positive integers. You will implement the algorithm using two different STL containers (`std::vector` and `std::list` or `std::deque`) and compare their performance.
